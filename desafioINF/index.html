Informe técnico

Guía para preparar el documento de entrega.

El desafío solicita un informe de máximo dos páginas. Utiliza estos apartados para comprobar que no falte información.

  • Problema: contexto y objetivo.
  • Modelo: integral, límites, variables y unidades.
  • Datos: tabla y procedencia de los valores.
  • Cálculo: procedimiento manual y condiciones de cada método.
  • Resultados: comparación de métodos y errores cuando exista referencia.
  • Conclusión: interpretación física y limitaciones.
Entregables adicionales: hojas con el desarrollo manual de los dos problemas asignados, enlace de la aplicación publicada, repositorio GitHub y evidencias de pruebas.
